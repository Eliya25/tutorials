Linux Exercise Bank — ‏100 תרגילים ו־10 מעבדות

מסלול מעשי ל־Ubuntu VM: מהתמצאות ב־filesystem ועד ניהול שירותים, networking, SSH, Bash, security ופתרון תקלות Production.

כללי בטיחות לפני שמתחילים

  • בצע את התרגילים ב־Ubuntu VM שלך, לא על שרת עבודה או מערכת צבאית.
  • צור snapshot ל־VM לפני תרגילי users, packages, disks, firewall ו־systemd.
  • כל תרגילי הקבצים יתבצעו רק בתוך ~/linux-practice-lab.
  • לפני rm,‏ chmod,‏ chown או פקודת sudo, הרץ pwd ו־ls -la ואמת את היעד המדויק.
  • אל תריץ פקודה שאינך יכול להסביר, ואל תדביק פקודות destructive מהאינטרנט.
  • אל תשנה SSH או firewall לפני שיש לך console ישיר או snapshot שממנו ניתן להתאושש.

הכנת המעבדה

mkdir -p ~/linux-practice-lab
cd ~/linux-practice-lab
pwd
touch LAB_ONLY
ls -la

בתחילת כל session: היכנס לתיקייה, הרץ pwd, וכתוב בקובץ notes מה עשית ומה למדת. בתרגיל שמבקש “לחקור”, השתמש ב־man,‏ --help ו־apropos לפני חיפוש פתרון.

רמה 1 — ניווט, תיקיות וקבצים: 1–20

1. איפה אני?

הרץ pwd, הסבר מהו absolute path וזהה את תיקיית הבית שלך.

2. רשימה בסיסית

השווה ls,‏ ls -l,‏ ls -a ו־ls -lah. הסבר כל עמודה ב־long listing.

3. מעבר בין תיקיות

תרגל cd עם absolute path, relative path,‏ ..,‏ .,‏ ~ ו־cd -.

4. בניית עץ תיקיות

צור projects/api/{src,tests,docs} בפקודה אחת עם mkdir -p.

5. יצירת קבצים

צור חמישה קבצים עם touch; בדוק timestamps עם stat והפעל touch שוב.

6. Copy

העתק file, שנה שם בעותק והעתק directory עם האפשרות המתאימה. ודא שהמקור נשאר.

7. Move ו־Rename

השתמש ב־mv פעם לשינוי שם ופעם להעברה. בדוק מה קורה אם היעד קיים.

8. מחיקה בטוחה

צור קובץ ניסוי ומחק אותו עם rm -i. מחק תיקייה ריקה עם rmdir. אל תשתמש ב־recursive removal.

9. זיהוי סוג קובץ

הפעל file על text, directory, executable ותמונה אם קיימת. הסבר למה extension אינו המקור היחיד.

10. קריאת קובץ

השווה cat,‏ less,‏ head ו־tail. בתוך less תרגל חיפוש ויציאה.

11. Line Numbers

הצג קובץ עם מספרי שורות באמצעות שתי פקודות שונות.

12. Wildcards

צור קובצי .log,‏ .txt ו־.json; תרגל *,‏ ? ו־character classes.

13. Quoting

צור קובץ ששמו מכיל spaces. גש אליו עם quotes ועם escaping. השווה single ו־double quotes סביב variable.

14. Absolute מול Relative

פתח אותו קובץ פעם מכל סוג path; שנה working directory והסבר למה relative path נשבר.

15. Metadata

השתמש ב־stat וזהה size, owner, permissions, inode ו־timestamps.

16. Find לפי שם

מצא את כל קובצי .log רק בתוך תיקיית המעבדה. אחר כך הוסף case-insensitive search.

17. Find לפי זמן וגודל

מצא קבצים ששונו לאחרונה וקבצים מעל גודל שקבעת. השתמש בקובצי מעבדה בלבד.

18. Locate מול Find

בדוק אם locate מותקן, והסבר database index מול traversal בזמן אמת.

19. Command Discovery

תרגל which,‏ type,‏ command -v ו־whereis על ls ועל alias.

20. Documentation

מצא באמצעות man את option שממיין ls לפי זמן. השתמש ב־apropos למציאת כלי לפי תיאור.

שער מעבר 1

אתה צריך לנווט בלי פחד, להסביר את מיקום ה־working directory ולבצע copy/move/delete רק אחרי אימות היעד.

רמה 2 — טקסט, Redirection, Pipes וחיפוש: 21–35

21. stdout ו־stderr

הרץ פקודה מצליחה ונכשלת. הפנה stdout ו־stderr לקבצים נפרדים באמצעות file descriptors.

22. Overwrite מול Append

השווה > ו־>>. הוכח מתי תוכן קודם נדרס.

23. Pipe ראשון

חבר ls -la ל־less. הסבר שה־pipe מעביר stdout כתוכן ולא arguments.

24. Grep בסיסי

חפש מילה בקובץ עם line numbers, case-insensitive ו־invert match.

25. Grep רקורסיבי

חפש TODO בכל קובצי המעבדה, תוך הכללת extension מסוים והחרגת directory.

26. Regex

מצא שורות שמתחילות ב־ERROR, כתובות IPv4 בסיסיות וכתובות email באמצעות grep -E.

27. Sort ו־Unique

מיין שמות, הסר כפילויות וספור שכיחות עם sort | uniq -c. הסבר למה sort קודם.

28. wc

ספור lines, words ו־bytes. צור pipeline שסופר כמה שורות log מכילות ERROR.

29. cut

צור CSV פשוט והוצא עמודות. הסבר מגבלות cut עבור CSV עם quotes.

30. tr

המר lowercase ל־uppercase, החלף delimiter ומחק תווים מסוימים מ־stream.

31. sed

החלף טקסט בתצוגה בלבד, אחר כך בקובץ copy. הדפס רק טווח שורות.

32. awk

מקובץ של name,role,salary הדפס עובדים מעל סף וחשב sum לפי עמודה.

33. xargs בטוח

צור רשימת filenames והעבר כ־arguments ל־stat. תמוך בשמות עם spaces באמצעות null delimiter.

34. tee

שמור output לקובץ ובמקביל הצג אותו. בנה pipeline קטן לניתוח log.

35. Log Report

מקובץ access log דמה, החזר status codes לפי שכיחות ואת חמשת ה־paths הנפוצים.

רמה 3 — Permissions, Users, Groups וקישורים: 36–50

36. קריאת Permissions

פענח את עשרת התווים הראשונים של ls -l: סוג, owner, group ו־others.

37. chmod Symbolic

הוסף והסר read/write/execute עם symbolic mode על script במעבדה.

38. chmod Numeric

צור permissions ‏644, 600, 755 ו־700 והסבר את החיבור הבינארי של 4/2/1.

39. Directory Permissions

בדוק בנפרד מה מאפשרים r, w ו־x על directory. השתמש בתיקיית ניסוי בלבד.

40. umask

בדוק umask נוכחי, צור file ו־directory והסבר כיצד permissions ההתחלתיות חושבו.

41. Identity

השווה whoami,‏ id,‏ groups ו־who.

42. Users Database

קרא בצורה בטוחה את /etc/passwd והסבר כל field. אל תערוך אותו ידנית.

43. Groups Database

חקור /etc/group וזהה primary מול supplementary groups.

44. sudo

השתמש ב־sudo -l כדי לראות הרשאות. הסבר למה לא עובדים כ־root כברירת מחדל.

45. משתמש מעבדה

לאחר snapshot, צור user זמני עם adduser, בדוק home/groups ואז מחק דרך כלי המערכת.

46. Shared Group

צור group מעבדה, הוסף שני users ובנה directory משותפת עם permissions מתאימות.

47. chown ו־chgrp

שנה owner/group לקובץ מעבדה ואמת עם stat. אל תפעל מחוץ למעבדה.

48. Hard Link

צור hard link, השווה inode, ערוך דרך אחד ומחק שם אחד. הסבר למה הנתונים נשארים.

49. Symbolic Link

צור symlink יחסי ומוחלט, הזז target וראה מתי הקישור נשבר.

50. setgid Directory

ב־shared lab directory הפעל setgid והוכח שקבצים חדשים יורשים group. הסבר sticky bit רעיונית.

שער מעבר 3

עליך להסביר 640 ו־750 בלי לנחש, ולהבדיל בין file permissions, directory permissions, ownership ו־group membership.

רמה 4 — Processes, Signals, Logs ו־systemd: 51–65

51. Process Snapshot

השווה ps,‏ ps aux ו־ps -ef; זהה PID, PPID, user ו־command.

52. Process Tree

השתמש ב־pstree וחקור parent/child של shell ופקודה שהרצת.

53. top

מצא processes לפי CPU/memory, החלף sorting וצא בלי להרוג דבר. נסה htop אם מותקן.

54. Background Job

הרץ sleep ברקע, בדוק jobs, העבר ל־foreground ועצור/המשך.

55. Signals

שלח SIGTERM לתהליך ניסוי ורק אחר כך SIGKILL לתהליך חדש. הסבר את ההבדל.

56. nice ו־renice

הרץ CPU demo קצר בעדיפות שונה. הסבר priority ולא “הגבלת CPU”.

57. Open Files

מצא files ו־sockets פתוחים של process עם lsof.

58. /proc

בחר PID שלך וחקור cmdline, status, fd ו־environ בזהירות.

59. Exit Codes

הרץ פקודה מצליחה ונכשלת ובדוק $?. חבר עם && ו־||.

60. journalctl

הצג logs מה־boot הנוכחי, לפי unit, לפי priority ובטווח זמן.

61. systemctl Inspect

בדוק status, is-active ו־is-enabled של service קיים. אל תשנה אותו עדיין.

62. Service Lifecycle

על service מעבדה בלבד תרגל start/stop/restart/reload והסבר את ההבדלים.

63. Unit File בסיסי

צור script בטוח שמדפיס heartbeat ו־user unit שמריץ אותו. בדוק logs ו־restart policy.

64. Failure Investigation

הכנס path שגוי ל־unit המעבדה, חקור status/journal, תקן ו־daemon-reload.

65. Graceful Shutdown

כתוב Python/Bash service שתופס SIGTERM, מסיים עבודה ומדפיס shutdown log.

רמה 5 — Packages, Environment ו־Shell: 66–75

66. apt Update מול Upgrade

הסבר מה כל אחת עושה לפני הרצה. הצג packages שניתנים לשדרוג בלי לשנות מערכת.

67. Package Ownership

מצא איזו package סיפקה binary קיים והצג את רשימת הקבצים שלה.

68. Install/Remove Lab Tool

לאחר snapshot, התקן כלי קטן, אמת version, הסר והסבר remove מול purge.

69. Environment Variables

צור variable מקומי, export אותו וראה אותו ב־child shell. הסבר inheritance חד־כיווני.

70. PATH

הוסף directory מעבדה זמנית ל־PATH והרץ script ללא path. אל תדרוס את PATH הקיים.

71. Shell Startup

זהה login מול interactive shell וקבצי startup הרלוונטיים ב־Ubuntu.

72. Aliases ו־Functions

צור alias תצוגה ו־shell function שמקבלת argument. הסבר מתי script עדיף.

73. Command History

חפש history, השתמש ב־reverse search והסבר למה אסור להקליד secrets בפקודה.

74. Shell Expansion

הדגם variable, command, arithmetic, brace, tilde ו־glob expansion ואת סדר ההשפעה של quoting.

75. Cron

צור job מעבדה שכותב timestamp לקובץ כל כמה דקות, עם absolute paths ו־redirect ל־log; לאחר הבדיקה הסר אותו.

רמה 6 — Storage ו־Filesystem: 76–82

76. Disk Usage

השווה df -h ו־du -sh. הסבר filesystem free space מול directory usage.

77. מי תופס מקום?

מצא את חמש התיקיות הגדולות בתוך המעבדה בלבד עם du ו־sort.

78. Inodes

בדוק df -i והסבר כיצד filesystem יכול להיגמר מ־inodes גם כשיש bytes פנויים.

79. lsblk ו־blkid

מפה block devices, partitions, filesystem types ו־mount points ללא שינוי.

80. mount

צפה mounts קיימים והסבר device, mount point ו־filesystem. אל תערוך /etc/fstab.

81. Archive

צור tar archive, הצג תוכן ללא extraction, חלץ לתיקיית יעד והשווה gzip מול archive.

82. Deleted but Open

פתח file בתהליך ניסוי, מחק את השם ומצא אותו ב־lsof +L1. הסבר מדוע המקום טרם שוחרר.

רמה 7 — Networking ו־SSH: 83–95

83. Interfaces ו־Addresses

השתמש ב־ip addr וזהה loopback, interface, IPv4, prefix ו־state.

84. Routing Table

הצג ip route, זהה default gateway והסבר כיצד route נבחר לפי longest prefix.

85. Neighbor Table

הצג ip neigh והסבר את הקשר בין IP ל־MAC ברשת המקומית.

86. ping נכון

בדוק loopback, gateway ו־host ציבורי עם מספר packets מוגבל. הסבר מה ping מוכיח ומה לא.

87. DNS

השתמש ב־dig או resolvectl ל־A, AAAA ו־NS. השווה שם ל־IP.

88. Listening Sockets

השתמש ב־ss -lntup וזהה protocol, local address, port ו־process.

89. HTTP עם curl

בדוק headers, status, redirects, timing ו־JSON endpoint. השתמש ב־example.com או שירות שלך.

90. Local HTTP Server

הרץ server מקומי זמני, מצא את socket עם ss, פנה אליו ב־curl וסגור בצורה מסודרת.

91. netcat מקומי

צור listener ו־client על localhost בשני terminals והעבר טקסט. אל תסרוק hosts חיצוניים.

92. Route Trace

השתמש ב־tracepath או traceroute ליעד מורשה והסבר hops ו־timeouts.

93. SSH Keys

צור key ייעודי למעבדה עם passphrase, בדוק permissions והסבר private מול public key. אל תפרסם private key.

94. SSH ל־VM

התחבר ל־Ubuntu VM ממחשב הבית, אמת host key והשתמש ב־verbose mode ל־diagnosis.

95. SCP ו־SFTP

העבר קובץ מעבדה בשני הכלים, אמת checksum לפני/אחרי והסבר interactive מול copy command.

רמה 8 — Bash Automation: 96–100

96. Script בטוח ראשון

Shebang, set -euo pipefail, arguments, usage ו־exit codes. הסבר כל option ולא רק העתק.

97. Backup Script

Archive תיקיית מעבדה לשם עם timestamp, אמת destination והסר backups ישנים לפי retention בטוח.

98. Health Check

בדוק process, port ו־HTTP status והחזר exit code מתאים. הוסף timeout ו־log.

99. Log Analyzer

קבל path כ־argument, אמת file, חשב errors/top paths והפק report. טפל ב־spaces.

100. Deployment Script מקומי

Validate config, copy artifact, restart user service, health check ו־rollback לגרסה קודמת אם נכשל.

שער סיום

אתה מוכן לעבוד על שרת מעבדה עצמאי כאשר אתה מסוגל לאתר בעיה לפי שכבות: process → logs → socket → route/DNS → permissions/storage, בלי להריץ פקודות אקראיות.

10 מעבדות מסכמות

1. Filesystem Scavenger Hunt

בנה עץ של 50 קבצים, מצא לפי שם/זמן/גודל, הפק archive ודוח checksums.

2. Permissions Lab

שני users ו־group חולקים project; רק owner יכול למחוק, הקבוצה יכולה לערוך וקבצים יורשים group.

3. Log Investigation

קבל logs עם failures, הפק timeline, top errors ו־root-cause hypothesis באמצעות grep/sed/awk.

4. Process Incident

Process צורך CPU, אחר מחזיק deleted file ושלישי לא מגיב ל־TERM. חקור וטפל לפי escalation מסודר.

5. systemd Service

פרוס אפליקציית Python קטנה כ־user service עם environment, restart, logs ו־graceful shutdown.

6. Disk Full Simulation

רק בתוך virtual disk/safe lab, חקור bytes מול inodes, deleted-open file ו־log cleanup. השתמש ב־snapshot.

7. Network Troubleshooting

אבחן שלושה תרחישים: DNS שבור, service מאזין רק ל־localhost, ו־port לא מאזין. כתוב decision tree.

8. SSH Hardening Lab

ב־snapshot ועם console fallback: key auth, user לא־root, permissions ו־logs. אל תנעל password לפני שבדקת session נוסף.

9. Backup and Restore

Backup של config+data, checksum, retention ו־restore לתיקייה חדשה. Backup נחשב רק אחרי restore test.

10. Production Debugging Capstone

Service לא זמין: בדוק systemd, journal, process, permissions, env, port, route, DNS, disk ו־resource pressure; כתוב RCA ופעולת מניעה.

קצב מומלץ

3–4 תרגילים ביום מתאימים לרמות 1–3. מרמה 4, עשה 1–2 תרגילים עמוקים. מעבדה מסכמת יכולה לקחת 2–4 sessions. לכל תרגיל רשום: הפקודה, מה ציפית, מה קרה ולמה.
