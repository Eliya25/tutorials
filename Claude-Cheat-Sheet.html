MCP

claude mcp add --transport http notion https://mcp.notion.com/mcp
claude mcp add --transport http gh URL --header "Authorization: Bearer TOKEN"
claude mcp add --transport stdio db -- npx -y some-mcp-server
claude mcp list / get NAME / remove NAME
  • Scope: ברירת מחדל local · --scope project = לצוות (.mcp.json בגיט) · --scope user = כל הפרויקטים שלך
  • סודות: ${VAR} בקונפיג, לא טוקנים בגיט

Skill — שלד מינימלי

# ~/.claude/skills/NAME/SKILL.md

disable-model-invocation: true   # רק אתה מפעיל
allowed-tools: Bash(git *)       # בלי חלונות אישור
---
Instructions here. $ARGUMENTS = user input.
  • הפעלה: /NAME args · שם התיקייה = שם הפקודה
  • אישי: ~/.claude/skills/ · פרויקט: .claude/skills/

תבנית פרומפט למשימה + כלל הזהב

המשימה: [מה, במשפט]  |  קבצים: @src/...  |  הקשר: [שגיאות מלאות, מה ניסיתי]
אילוצים: [מה אסור לשבור]  |  הצלחה = [טסטים עוברים / X קורה]
תתחיל בתוכנית קצרה לפני שאתה נוגע בקוד.
  • כלל שני התיקונים: קלוד טעה פעמיים ברצף? /clear ופרומפט חדש עם מה שלמדת. אל תתווכח עם סשן מלוכלך.
  • כלל שתי הפעמים: תיקנת אותו דבר פעמיים? → שורה ב-CLAUDE.md. חזרת על תהליך פעמיים? → Skill.
  • בסוף כל משימה: "תריץ טסטים" + סקירת diff. תמיד.
