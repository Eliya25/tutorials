תרגול Python — מהיסודות עד Backend

המסלול נועד להחזיר לך עצמאות בכתיבת קוד. אין פתרונות מלאים בעמוד; יש דרישות, בדיקות קבלה ורמזים מדורגים. פתח רמז רק אחרי ניסיון אמיתי.

נוהל עבודה

  1. כתוב plan קצר לפני קוד.
  2. עבוד 25–40 דקות בלי AI.
  3. הרץ דוגמאות וכתוב tests משלך.
  4. אם נתקעת, פתח רמז אחד בלבד.
  5. רק אחרי פתרון בקש Code Review—לא rewrite.
  6. רשום מה השתבש ומה למדת.

רמה 1 — שליטה בתחביר ובנתונים

1. מנתח ציונים

כתוב פונקציה שמקבלת רשימת ציונים ומחזירה count, ממוצע, מינימום, מקסימום וכמות עוברים. רשימה ריקה צריכה להחזיר תוצאה מוגדרת ולא לקרוס.

יסודות list · conditions · functions

רמז

החלט מראש מה המשמעות של ממוצע ברשימה ריקה. אל תחזור על מעבר ברשימה ללא צורך.

2. ספירת מילים מנורמלת

קבל טקסט והחזר dictionary של שכיחויות. התעלם מאותיות גדולות/קטנות ומסימני פיסוק בסיסיים. הצג את חמש המילים הנפוצות.

רמז

הפרד normalization, counting ו־presentation לשלוש פונקציות.

3. אינדקס משתמשים

המר רשימת dictionaries של משתמשים למיפוי לפי ID. זהה ID כפול וזרוק exception ברור במקום לדרוס בשקט.

רמז

בדוק membership לפני ההשמה. צור exception ייעודי.

4. Group By כללי

ממש group_by(items, key_fn) שמקבלת iterable ופונקציה ומחזירה dict של קבוצות. אל תניח שהקלט הוא list.

רמז

dict.setdefault או defaultdict. אל תעבור פעמיים על generator.

5. Flatten בטוח

שטח רשימה בעומק אחד בלבד. לאחר מכן כתוב גרסה רקורסיבית לרשימות מקוננות. Strings אינם צריכים להתפרק לתווים.

רמז

הגדר במפורש מה נחשב container. רקורסיה צריכה base case.

6. ולידציית סיסמה

החזר את כל סיבות הכישלון, לא רק הראשונה: אורך, אות גדולה, קטנה, ספרה ותו מיוחד. הפרד policy מהפונקציה.

רמז

אסוף errors לרשימה; פונקציות any עם predicates עוזרות.

7. Merge של Configuration

מזג default config, file config ו־environment config לפי סדר קדימות. אל תשנה אף input. הוסף תמיכה ב־nested dictionaries.

רמז

Shallow copy לא מספיק ל־nested merge. כתוב recursive merge שמחזיר dict חדש.

8. Parser לפקודת CLI

המר מחרוזת כמו add "buy milk" --priority high למבנה נתונים. טפל בגרשיים ובפקודה לא מוכרת.

רמז

בדוק את shlex.split; אין צורך לכתוב tokenizer מאפס.

רמה 2 — Python נכונה ומודולרית

9. Immutable Money

צור dataclass של כסף עם amount ב־minor units ו־currency. תמוך בחיבור רק אם המטבע זהה. אובייקט לא יכול להשתנות אחרי יצירה.

רמז

frozen=True. בדוק invariant ב־__post_init__.

10. Repository בזיכרון

הגדר Protocol ל־TaskRepository ומימוש InMemory. תמוך ב־save/get/list/delete והחזר copies או objects immutable כדי למנוע mutation מבחוץ.

רמז

ה־service צריך להיות תלוי ב־Protocol, לא במחלקה הקונקרטית.

11. Context Manager למדידה

צור measure(name) לשימוש עם with. הוא חייב למדוד גם כשהבלוק זורק exception ולא לבלוע אותה.

רמז

השתמש ב־contextlib.contextmanager וב־try/finally.

12. Decorator של Retry

כתוב decorator שמנסה פעולה שוב רק עבור exceptions שנבחרו, עם max attempts ו־exponential backoff. שמור metadata של הפונקציה.

רמז

functools.wraps. הגדר האם attempts כולל את הניסיון הראשון. אל תעשה retry לכל Exception.

13. Generator לקובץ גדול

קרא קובץ אירועים שורה־שורה, דלג על שורות ריקות והחזר batches בגודל נתון. אל תטען את הקובץ כולו.

רמז

השתמש ב־yield ושחרר את batch אחרי כל yield.

14. Pipeline של Validators

כל validator מקבל ערך ומחזיר רשימת שגיאות. חבר validators בלי שיכירו זה את זה. הוסף type hints מלאים ו־tests.

רמז

הגדר type alias ל־Callable ושמור את ה־pipeline כ־Sequence.

15. Serialization Versioned

שמור Task ל־JSON עם version. טען גם פורמט v1 ישן והמר אותו ל־model החדש. דחה version עתידי לא מוכר.

רמז

הפרד wire schema מה־domain object; migration היא פונקציה מפורשת.

רמה 3 — Backend, I/O ו־Concurrency

16. HTTP Client עמיד

עטוף client חיצוני עם timeout, error mapping ו־retry רק ל־429/5xx. הזרק את ה־client כדי לבדוק בלי רשת.

רמז

הפרד transport errors, protocol errors ו־domain errors.

17. Async Fetch עם מגבלה

קבל 100 URLs ושלוף אותם במקביל, אך לכל היותר 10 בקשות פעילות. שמור תוצאה או שגיאה לכל URL.

רמז

asyncio.Semaphore. ודא שלכל בקשה timeout ושכישלון אחד לא מוחק את כל הדוח.

18. Producer–Consumer

צור producer שקורא records ושני consumers שמעבדים אותם באמצעות asyncio.Queue. בצע shutdown ללא אובדן עבודה.

רמז

חקור task_done,‏ join ו־sentinel. חשוב מי אחראי לסיום.

19. Race Condition במונה

כתוב תוכנית שמדגימה lost update בין threads. תקן באמצעות Lock, ואז הסבר למה ה־GIL לא היה חוזה correctness.

רמז

הפרד read, delay ו־write כדי להגדיל את חלון ה־race.

20. CPU-bound Worker Pool

חשב checksums לקבצים רבים והשווה זמן של loop רגיל, threads ו־processes. כתוב מסקנה המבוססת על מדידה.

רמז

הפרד זמן I/O מזמן CPU ואל תסיק מסקנה מריצה יחידה.

21. Transaction Service

בנה service להעברה בין חשבונות. אם השלב השני נכשל, אסור להשאיר חיוב חלקי. כתוב fake transaction manager ובדיקות rollback.

רמז

גבול ה־transaction שייך ל־use case, לא לכל repository call בנפרד.

22. Cache עם TTL

ממש cache בזיכרון עם get/set, TTL ו־clock מוזרק. אל תשתמש ב־sleep בבדיקות. הגדר התנהגות ל־stampede.

רמז

שמור expiration timestamp; הזרק callable שמחזיר monotonic time.

Debugging — מצא, הסבר, תקן ובדוק

23. ברירת מחדל שדלפה

def register(name, users=[]):
    users.append(name)
    return users

הוכח את התקלה בשתי קריאות, תקן והוסף regression test.

24. Coroutine שלא רצה

async def handler():
    result = fetch_user()
    return result["name"]

נניח ש־fetch_user היא async. הסבר מהו האובייקט ב־result, תקן וטפל ב־timeout.

25. Exception שנבלעה

try:
    save_order(order)
except Exception:
    return {"ok": False}

הסבר אילו תקלות אבדו. תכנן mapping בין infrastructure, domain ו־HTTP errors.

26. Shallow Copy מפתיע

original = {"db": {"host": "prod"}}
copy = original.copy()
copy["db"]["host"] = "test"

נבא את original, הסבר object graph ותן שתי דרכי תיקון עם trade-offs.

27. Memory Blow-up

rows = [json.loads(line) for line in open("events.jsonl")]
result = [transform(row) for row in rows]

שכתב ל־streaming, ודא סגירת קובץ וטפל בשורה פגומה בלי לאבד מספר שורה.

פרויקט מסכם — TaskFlow CLI

בנה מנהל משימות אמיתי ב־Python, ללא framework וללא קוד שנוצר עבורך. המטרה היא להוכיח שליטה בשפה, design, persistence ו־testing.

יכולות חובה

  • פקודות add, list, show, update, complete, delete ו־search.
  • Task עם ID, title, description, status, priority, tags ו־timestamps.
  • שמירה אטומית ל־JSON וטעינת schema version קודם.
  • Domain validation ו־exceptions ברורות.
  • שכבות CLI, application, domain ו־infrastructure.
  • Type hints מלאים ו־Ruff/mypy.
  • Unit tests ללוגיקה ו־integration tests ל־JSON repository.
  • Logging ללא מידע רגיש ו־exit codes תקינים.

שלבי בנייה

  1. כתוב requirements ו־invariants.
  2. בנה domain ללא קבצים או CLI.
  3. הוסף repository protocol ומימוש memory.
  4. כתוב services ו־tests.
  5. הוסף JSON persistence.
  6. חבר CLI.
  7. בדוק corrupted file, duplicate ID ו־failed write.
  8. כתוב README עם החלטות ו־trade-offs.

הרחבות

SQLite repository, export CSV, recurring tasks, optimistic version, async sync server. בצע הרחבות רק אחרי שכל דרישות החובה יציבות.

Definition of Done

  • התקנה והרצה מסביבה נקייה.
  • כל tests עוברים ואין warnings מוסתרים.
  • אין business logic בתוך parser ה־CLI.
  • קובץ לא נפגם גם אם write נכשל באמצע.
  • אתה מסוגל להסביר כל קובץ וכל החלטה בלי AI.
