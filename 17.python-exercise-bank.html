רמה 1 — לוגיקה בסיסית: 1–20

המטרה: לתרגם דרישה ל־variables, conditions ו־loops בלי להסתבך בארכיטקטורה.

1. חיובי, שלילי או אפס

כתוב פונקציה שמקבלת מספר ומחזירה אחת משלוש מחרוזות. בדוק גם float.

2. זוגי או אי־זוגי

החזר boolean שמציין אם integer זוגי. הגדר מה קורה לקלט שאינו integer.

3. הגדול משלושה

קבל שלושה מספרים והחזר את הגדול בלי להשתמש ב־max. טפל בשוויון.

4. שנת קפיצה

ממש את כללי leap year: מתחלקת ב־4, למעט מאות שאינן מתחלקות ב־400.

5. מחיר לאחר הנחה

קבל מחיר ואחוז הנחה. אמת שטווח ההנחה 0–100 והחזר מחיר מעוגל לשתי ספרות.

6. ציון לאות

המר 0–100 ל־A/B/C/D/F. קלט מחוץ לטווח צריך לעורר ValueError.

7. סכום 1 עד N

פתור פעם בלולאה ופעם בנוסחה. הסבר את סיבוכיות הזמן של כל פתרון.

8. לוח הכפל

החזר list של עשר תוצאות עבור מספר נתון. אל תדפיס מתוך פונקציית החישוב.

9. עצרת

חשב factorial בלולאה. הגדר מה קורה ל־0 ולמספר שלילי.

10. ספירת ספרות

ספור ספרות ב־integer ללא המרה ל־string; אחר כך כתוב פתרון עם string והשווה.

11. היפוך מספר

הפוך 1234 ל־4321 באמצעות פעולות חשבון. שמור את סימן המספר.

12. סכום ספרות

חשב סכום ספרות של מספר חיובי ושלילי. החלט כיצד להתייחס לסימן.

13. מספר ראשוני

בדוק primality בלי לחלק עד המספר עצמו. הסבר מדוע מספיק לבדוק עד השורש.

14. כל הראשוניים עד N

השתמש בפונקציה מהתרגיל הקודם. לאחר מכן חקור Sieve of Eratosthenes.

15. FizzBuzz מורחב

כפולות 3→Fizz, ‏5→Buzz, ‏7→Pop ושילובים. אל תשכפל conditions לכל שילוב.

16. ספירת תו

קבל string ותו וספור הופעות ללא count. הוסף אפשרות case-insensitive.

17. היפוך מחרוזת

פתור בלולאה וב־slicing. הסבר איזה פתרון קריא יותר ואיזה יוצר objects זמניים.

18. Palindrome

התעלם מרווחים, punctuation ו־case. אל תערבב normalization עם הבדיקה.

19. ספירת תנועות

ספור vowels באנגלית והחזר dictionary של הכמות לכל תנועה.

20. Guessing Engine

פונקציה מקבלת secret ורשימת guesses ומחזירה באיזה ניסיון הצליחו או None. היא לא קוראת input בעצמה.

שער מעבר 1

עבור הלאה רק אם פתרת לפחות 16/20 ללא פתרון חיצוני, ואתה מסוגל לבצע dry run ללולאה ולהסביר כל variable.

רמה 2 — Collections ועיבוד נתונים: 21–40

21. מינימום ומקסימום

מצא בשני משתנים במעבר אחד וללא min/max. רשימה ריקה צריכה לקבל חוזה מפורש.

22. הסרת כפילויות

שמור את סדר ההופעה הראשון. פתור עם set עזר והסבר למה set(items) לא מבטיח את אותו חוזה.

23. האיבר השני בגודלו

התעלם מכפילויות ופתור במעבר אחד. בדוק רשימה עם פחות משני ערכים ייחודיים.

24. חיתוך רשימות

החזר ערכים משותפים ללא כפילויות ובסדר הרשימה הראשונה.

25. הזזת אפסים

העבר אפסים לסוף ושמור סדר יחסי של שאר הערכים. כתוב גרסה שמחזירה חדש וגרסה in-place.

26. Rotation

סובב list ימינה K מקומות; טפל ב־K גדול מאורך הרשימה וברשימה ריקה.

27. Chunking

חלק iterable לקבוצות בגודל N. אל תאבד קבוצה חלקית בסוף.

28. Merge Sorted Lists

מזג שתי רשימות ממוינות ב־O(n+m), ללא sort בסוף.

29. Two Sum

החזר indices של שני ערכים שסכומם target. התחל ב־O(n²), ואז שפר עם dictionary.

30. Sliding Average

חשב ממוצע לכל חלון בגודל K. כתוב תחילה פתרון פשוט ואז sliding window ב־O(n).

31. שכיחות מילים

נרמל טקסט והחזר את עשר המילים הנפוצות, עם tie-break אלפביתי.

32. Anagrams

בדוק אם שתי מחרוזות anagrams; לאחר מכן קבץ רשימת מילים לקבוצות anagram.

33. Group Users by Role

החזר dict[str, list[User]]. משתמש ללא role נכנס ל־unknown.

34. אינדקס לפי ID

המר רשימת records ל־dictionary. ID כפול צריך לגרום ל־exception במקום דריסה.

35. Merge Profiles

מזג default, stored ו־request profile לפי priority בלי לשנות inputs. תמוך ב־nested dictionaries.

36. Inventory Report

קבל מוצרים והחזר total value, out-of-stock, low-stock והקטגוריה היקרה ביותר.

37. Orders by Customer

קבץ הזמנות לפי לקוח, חשב total לכל לקוח ומיין בירידה ללא mutation של הקלט.

38. Pagination

ממש offset pagination שמחזירה items ו־metadata. אמת page/page_size.

39. Cursor Pagination בסיסית

עבוד עם records ממוינים לפי ID והחזר next cursor. הסבר מה קורה אם record נמחק.

40. Diff בין Dictionaries

החזר keys שנוספו, נמחקו ושונו, כולל old/new values.

שער מעבר 2

פתור לפחות 15/20, כולל 29, 30, 36 ו־37. עליך לדעת להסביר מתי list, set או dict נותנים representation מתאים יותר.

רמה 3 — Functions ו־Problem Decomposition: 41–55

41. Password Policy

בנה validators עצמאיים שמחזירים את כל השגיאות. ה־policy צריך להיות configurable.

42. Pipeline

ממש pipe(value, functions) שבו כל פונקציה מקבלת את תוצאת הקודמת. טפל בכשל עם context.

43. Generic group_by

קבל iterable ו־key function. אל תניח שניתן לעבור על input פעמיים.

44. Memoization

כתוב decorator עם key function ו־cache מוגבל. החלט מה קורה ל־exceptions.

45. Retry סינכרוני

Decorator עם max attempts, backoff ו־exceptions מותרים. הזרק sleep כדי לבדוק בלי להמתין.

46. Rate Limiter פשוט

Fixed window לפי user ID עם clock מוזרק. בדוק בדיוק את גבול החלון.

47. TTL Cache

ממש get/set עם expiration ו־max size. אל תשתמש ב־sleep ב־tests.

48. Event Dispatcher

הרשם handlers לפי event type, אפשר unsubscribe, ואל תאפשר שינוי הרשימה לשבור dispatch פעיל.

49. Command Parser

פרש פקודות CLI עם quoted strings, flags ו־validation. הפרד tokenization, parsing ו־execution.

50. Rule Engine

מערכת שמקבלת rules ומחזירה reasons לקבלת/דחיית loan request. אל תקודד את כל הכללים ב־if אחד.

51. CSV Aggregator

עבד rows כ־iterable, אמת כל row והחזר report כולל rejected rows וסיבות.

52. State Machine להזמנה

הגדר transitions חוקיים בין pending/paid/shipped/cancelled. מעבר לא חוקי מעלה domain error.

53. Idempotent Command

קבל command ID ושמור תוצאות, כך שאותה פקודה פעמיים לא תבצע side effect נוסף.

54. Booking Conflict

קבל intervals ובדוק התנגשות; אחר כך מצא slots פנויים בטווח יום.

55. Expense Report

פרק ל־parse, validate, categorize, aggregate ו־format. כל שלב צריך להיות ניתן לבדיקה בנפרד.

שער מעבר 3

בחר שלושה תרגילים והסבר את הפירוק לפני הקוד. עליך לכתוב functions קטנות לפי אחריות בלי להפוך כל שתי שורות ל־abstraction.

רמה 4 — OOP ו־Domain Modeling: 56–68

56. BankAccount

הגן על invariant של balance, הוסף deposit/withdraw ו־transaction history immutable.

57. Money Value Object

Dataclass frozen עם minor units ו־currency. חיבור בין מטבעות שונים אסור.

58. Task Entity

ID, title, status ו־timestamps. Transition ל־completed צריך להיות method ולא שינוי שדה חופשי.

59. Shopping Cart

Cart items, quantities, totals והנחות. הפרד Product identity ממחיר בזמן ההוספה.

60. Library Loans

BookCopy, Member ו־Loan. אי אפשר להשאיל עותק מושאל או לעבור את מגבלת החבר.

61. Workout Domain

Workout, ExerciseSet ו־Exercise. אמת reps/weight וזמן סיום לאחר התחלה.

62. Notification Protocol

הגדר Protocol ושלושה adapters: console, fake ו־email stub. Service תלוי רק בחוזה.

63. Repository Protocol

save/get/list/delete עם InMemory implementation. קבע semantics ל־missing ול־duplicate.

64. Unit of Work Fake

Context manager שמבצע commit או rollback. כתוב tests ל־exception באמצע use case.

65. Pricing Strategies

Regular, percentage ו־buy-X-get-Y ללא if לפי type בתוך Checkout.

66. Audit Trail

Domain events עבור שינויים חשובים. אירוע צריך להיות immutable ולהכיל רק data נחוצה.

67. Optimistic Version

Entity עם version; repository דוחה save אם הגרסה השתנתה מאז הקריאה.

68. Service Layer

Use case של complete task שמחבר repository, clock ו־event publisher ללא framework.

רמה 5 — Files, Exceptions ו־Modules: 69–78

69. Safe Text Reader

קרא UTF‑8 line-by-line, שמור line number ודווח על decoding/format errors.

70. JSON Repository

שמור וטעון entities עם schema version. קובץ חסר שונה מקובץ corrupted.

71. Atomic Writer

כתוב temp file ואז replace. הזרק failure לפני replace והוכח שהקובץ המקורי נשאר.

72. JSONL Streaming

עבד מיליון events ללא טעינה מלאה והחזר report של accepted/rejected.

73. CSV Importer

מפה headers, המר types, אסוף שגיאות לפי row והמשך אחרי row פגום.

74. Configuration Loader

מזג defaults, file ו־environment; המר booleans/integers ואמת שדות חובה.

75. Custom Error Hierarchy

Domain, Validation ו־Infrastructure errors עם cause. אל תדליף פרטים פנימיים למשתמש.

76. Transaction Context Manager

commit בהצלחה ו־rollback בכשל, תוך שימור exception המקורית.

77. Package Refactor

פצל קובץ של 300 שורות ל־domain/application/infrastructure בלי circular imports.

78. CLI Entry Point

בנה python -m taskflow, exit codes, stderr לשגיאות ו־stdout לתוצאה.

רמה 6 — Testing ו־Debugging: 79–88

79. Test Matrix

כתוב parametrize לפונקציית validation עם valid, boundaries ו־invalid types.

80. Fake Clock

בדוק expiry ו־timestamps ללא sleep או patch גלובלי.

81. Fake Repository

בדוק service כולל success, not found, conflict ו־save failure.

82. Property-Based Thinking

ל־reverse הגדֵר properties: פעמיים מחזיר מקור ואורך נשמר. אחר כך השתמש ב־Hypothesis.

83. Regression: Mutable Default

הוכח ששתי קריאות חולקות list, תקן וכתוב test שמונע חזרה.

84. Regression: Shallow Copy

שחזר mutation של nested config ותקן עם contract ברור, לא אוטומטית deepcopy.

85. Lost Exception Context

קוד תופס Exception וזורק חדשה. תקן עם exception צרה ו־raise ... from.

86. Hidden Nondeterminism

Test תלוי ב־datetime.now ובסדר set. הפוך אותו deterministic.

87. Memory Growth

Cache לא מוגבל גדל בכל request. כתוב reproduction, מדידה ו־eviction policy.

88. Integration Test ל־Filesystem

השתמש ב־temporary directory ובדוק write/read/corruption ללא תלות במחשב שלך.

רמה 7 — Async ו־Backend Logic: 89–100

89. Async Delay

כתוב coroutine שמדגימה concurrency של שלוש המתנות ומדוד מול הרצה סדרתית.

90. Fetch with Timeout

עטוף client מוזרק ב־timeout ומפה timeout ל־error של השכבה שלך.

91. Bounded Concurrency

עבד 100 items עם מקסימום 10 פעילים ושמור תוצאה/שגיאה לכל item.

92. Producer–Consumer

Queue, producer ושני consumers עם shutdown שלא מאבד עבודה.

93. Cancellation Cleanup

בטל task באמצע והוכח ש־resource נסגר ו־CancelledError אינה נבלעת.

94. Retry Async

Backoff, jitter, cancellation ו־retry predicate. אל תעשה retry ל־validation.

95. In‑Flight Deduplication

חמש קריאות לאותו key מפעילות fetch אחד; כשל מסיר את ה־promise/future מה־cache.

96. Thread Race

שחזר lost update, תקן עם Lock והסבר למה GIL אינו חוזה correctness.

97. Process Pool

השווה sequential/threads/processes ל־CPU task וכתוב מסקנה ממדידה.

98. Idempotent Order Creation

אותו request ID מחזיר אותה תוצאה ואינו יוצר order נוסף, גם בשתי קריאות מקבילות.

99. Cursor Feed

Feed עם ordering יציב לפי timestamp+ID. הוסף records בין pages ובדוק שאין כפילות.

100. Complete Workout Use Case

אמת ownership/state, חשב summary, שמור transactionally ופרסם event רק אחרי הצלחה.

8 Mini‑Projects לקראת Django

פרויקט 1 — Number & Text Toolkit

CLI שמפעיל 8–10 תרגילי רמה 1, עם parsing, errors ו־tests. המטרה היא functions וארגון בסיסי.

פרויקט 2 — Personal Expense Analyzer

ייבוא CSV, validation, קטגוריות, דוח חודשי ו־export JSON. המטרה היא data processing ו־files.

פרויקט 3 — TaskFlow CLI

Tasks, statuses, JSON repository, atomic write, search, tests ו־logging. המטרה היא שכבות ו־persistence.

פרויקט 4 — Workout Domain

Workout, exercises, sets, templates ו־progress calculations בזיכרון עם service ו־tests. זה יהיה ה־domain שתעביר אחר כך ל־Django.

פרויקט 5 — Booking Engine

Resources, time slots, conflict detection, cancellation ו־optimistic version. המטרה היא invariants ו־concurrency thinking.

פרויקט 6 — Async API Aggregator

שלושה fake providers, timeout, retry, bounded concurrency, partial results ו־structured logs.

פרויקט 7 — In‑Memory REST Domain

לפני web framework, בנה request-like commands, validation, services, repositories ו־error mapping. אחר כך חבר FastAPI או Django.

פרויקט 8 — Django Preparation Capstone

Workout Tracking core מלא: entities, use cases, repository protocols, pytest ו־JSON adapter. בשלב הבא החלף רק את adapter ב־Django ORM ואת ה־interface ב־DRF.

Definition of Done לכל Mini‑Project

  • README עם requirements, assumptions ו־commands.
  • אין business logic ב־CLI או framework layer.
  • Errors צפויות מטופלות ו־tracebacks אינן נבלעות.
  • Unit tests ללוגיקה ו־integration tests ל־adapter.
  • Ruff ו־type checker עוברים.
  • אתה מסוגל להסביר כל קובץ, flow ו־trade‑off בלי AI.
