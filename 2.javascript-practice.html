תרגול JavaScript — מהיסודות עד Node.js

תרגילים לכתיבה עצמאית, reasoning, async ו־debugging. בכל משימה כתוב תחילה דוגמאות קלט/פלט, edge cases ו־complexity צפויה.

כללי התרגול

  1. Attempt ראשון ללא AI וללא autocomplete שמייצר פונקציות.
  2. אל תפתח רמז לפני שיש לך פתרון חלקי או הסבר מדויק למה נתקעת.
  3. כתוב tests, כולל קלט ריק ושגוי.
  4. אחרי שסיימת, בקש review בלבד והשווה חלופות.

רמה 1 — שפה ועיבוד נתונים

1. סטטיסטיקת הזמנות

קבל מערך orders והחזר revenue, average, count לפי status והלקוח בעל ההוצאה הגבוהה ביותר. אל תשנה את הקלט.

רמז

התחל בלולאה אחת ואובייקט accumulator; רק אחר כך שקול reduce.

2. Group By גנרי

ממש groupBy(items, keySelector). טפל במפתח מסוכן כמו __proto__.

רמז

Map מונע כמה בעיות שיש לאובייקט רגיל כמפה.

3. Deep Get

ממש get(obj, "user.address.city", fallback) בלי להשתמש ב־library. החלט איך arrays ומפתח חסר עובדים.

רמז

פצל path והתקדם עם optional checks; אל תבלבל בין missing לבין ערך falsy.

4. Deduplicate לפי אסטרטגיה

הסר כפילויות לפי email case-insensitive. שמור את הראשון בגרסה אחת ואת האחרון בשנייה.

רמז

Map שומר insertion order; חשוב מתי אתה מכניס ומתי רק מעדכן.

5. Immutable Update

עדכן כתובת של user בתוך state מקונן בלי לשנות שום object קיים. כתוב assertions שמוכיחים identity נכון.

רמז

צריך להעתיק כל level לאורך הנתיב, לא את כל העולם.

6. Normalized Search

חפש משתמשים לפי שם/email בלי תלות ב־case ורווחים. הפרד normalization מהחיפוש.

7. Frequency Window

מצא את התו הראשון שאינו חוזר ואת המילה הנפוצה ביותר. הסבר time/space complexity.

8. Validation Result

בנה validators שמחזירים את כל השגיאות עבור payload של יצירת משתמש. אין לזרוק exception עבור קלט צפוי ושגוי.

רמז

הבדל בין validation failure לבין programming/infrastructure failure.

רמה 2 — Functions, closures ו־object model

9. Once

כתוב once(fn) שמריץ את fn פעם אחת ומחזיר אותה תוצאה בהמשך. החלט מה קורה אם הקריאה הראשונה זרקה.

רמז

Closure צריך לשמור גם state וגם result; exception policy היא חלק מהחוזה.

10. Memoize עם Key Function

ממש memoization שמקבל key selector, תומך בערכים falsy ואינו מתנגש בין אובייקטים שונים.

רמז

אל תשתמש ב־if (cache[key]). שקול Map/WeakMap לפי החוזה.

11. Event Emitter קטן

ממש on,‏ off,‏ once ו־emit. Listener שמסיר את עצמו בזמן emit לא ישבור iteration.

רמז

Snapshot של listeners נותן semantics יציבים.

12. Private Counter

צור counter פעם עם closure ופעם עם class private field. השווה encapsulation ו־memory.

13. Pipeline

ממש pipe(...functions) וגרסה async שתומכת גם בפונקציות sync. שמור stack trace שימושי.

14. Custom Error Hierarchy

צור ValidationError, ConflictError ו־ExternalServiceError עם cause ו־metadata בטוח ללוגים.

רמה 3 — Promises, Event Loop ו־Concurrency

15. Delay ו־Timeout

כתוב delay(ms, signal) שניתנת לביטול, ואז withTimeout(promise, ms) שלא משאיר timer מיותר.

רמז

Promise.race לבדו לא מבטל את העבודה המפסידה. השתמש ב־AbortController כשאפשר.

16. Retry נכון

ממש retry עם exponential backoff, jitter, max attempts ו־predicate שקובע אם התקלה retryable.

רמז

אל תעשה retry ל־validation או authentication errors; העבר AbortSignal.

17. Promise Pool

עבד 100 משימות עם concurrency של 5, שמור את סדר התוצאות והחזר success/error לכל item.

רמז

כמה workers חולקים index; אין צורך להפעיל את כל ה־promises מראש.

18. Event Loop Prediction

console.log("A");
setTimeout(() => console.log("B"), 0);
Promise.resolve().then(() => console.log("C"));
queueMicrotask(() => console.log("D"));
console.log("E");

נבא את הסדר והסבר call stack, microtask queue ו־timer phase. לאחר מכן הוסף nested microtask.

19. Async Cache Deduplication

אם חמש בקשות לאותו key מגיעות יחד, הפעל fetch אחד בלבד ושתף promise. כישלון לא צריך להישאר cache לנצח.

רמז

Cache את ה־in-flight promise ומחק ב־catch/finally לפי policy.

20. Graceful Worker

צור worker שמעבד queue, מפסיק לקבל עבודה ב־shutdown, מחכה ל־inflight עם deadline ואז מבטל.

רמה 4 — Node.js מעשי

21. JSON File Repository

בנה repository אסינכרוני עם atomic write, schema version וטיפול ב־corrupted file.

רמז

כתוב temp file באותה תיקייה ואז rename. חשוב על שתי כתיבות במקביל.

22. HTTP Router ללא Framework

תמוך ב־method, path parameters, query ו־JSON body עם size limit. החזר error envelope אחיד.

23. Stream Transform

קרא CSV גדול, המר records וכתוב JSONL בלי לטעון הכול. טפל ב־backpressure ובשורה שגויה.

רמז

השתמש ב־pipeline; אל תתעלם מ־write שמחזיר false.

24. Structured Logger

כתוב logger ל־JSON עם level, timestamp, requestId ו־redaction לשדות password/token.

25. Rate Limiter

ממש fixed window ואז token bucket בזיכרון. בדוק boundary ו־clock מוזרק.

Debugging

26. forEach שלא מחכה

items.forEach(async item => {
  await save(item);
});
console.log("done");

הסבר ותקן פעם אחת sequential ופעם אחת concurrent עם limit.

27. Truthy Cache Bug

if (cache[key]) return cache[key];

הדגם כשל עם 0, false ומחרוזת ריקה; תקן בלי לשנות semantics.

28. Lost Error Context

catch (error) {
  throw new Error("Request failed");
}

שמור cause, הוסף context בטוח ואל תדליף secrets ללקוח.

29. Memory Leak ב־Listener

Endpoint מוסיף listener גלובלי בכל request ולעולם לא מסיר. כתוב reproduction, מדידה ותיקון.

30. Blocking Event Loop

בקשת HTTP מחשבת hash כבד ומעלה latency לכל המשתמשים. מדוד event-loop delay ובחר Worker Thread, process או queue.

פרויקט מסכם — TaskFlow HTTP API ללא Framework

בנה API ב־Node.js core בלבד כדי להבין מה framework עושה עבורך.

דרישות

  • Routes ל־CRUD, filter, sort ו־cursor pagination.
  • Router קטן עם path parameters.
  • JSON body parser עם size limit ו־validation.
  • Repository לקובץ JSON עם atomic writes.
  • Error hierarchy ו־response envelope עקבי.
  • Request ID, structured logs ו־latency.
  • Graceful shutdown ו־health endpoint.
  • Unit ו־integration tests עם test runner המובנה של Node.

Milestones

  1. Domain ופונקציות טהורות.
  2. Repository memory ו־tests.
  3. HTTP routing ו־validation.
  4. Persistence ו־concurrency protection.
  5. Observability ו־shutdown.
  6. README שמסביר event loop, backpressure ו־trade-offs.

Definition of Done

אין framework, אין global mutable state לא מבוקר, כל promise מטופל, קלט גדול נדחה, shutdown אינו מאבד request פעיל, ואתה מסוגל לבנות מחדש את השלד ללא AI.
