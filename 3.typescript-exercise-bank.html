TypeScript Exercise Bank — ‏100 תרגילים ו־8 מעבדות

מסלול מעשי מהטיפוס הראשון ועד modeling, narrowing, generics, advanced types, async, runtime validation ו־Backend type-safe. המטרה: לכתוב קוד שאתה מסוגל להסביר ולהגן עליו, לא להשתיק את ה־compiler.

איך עובדים

  1. הפעל strict. אל תשתמש ב־any,‏ as any או @ts-ignore אלא אם התרגיל דורש לנתח אותם.
  2. לפני הקוד כתוב מהו shape של הנתונים, מה יכול להיכשל ומה צריך להיות ידוע בזמן compile לעומת runtime.
  3. נסה להבין את הודעת השגיאה לפני שאתה משנה קוד. העתק למחברת את המשפט המרכזי מהשגיאה במילים שלך.
  4. הרץ tsc --noEmit ובדיקות. קוד שמתקמפל אך נכשל בזמן ריצה אינו פתרון.
  5. אל תבקש פתרון מ־AI לפני ניסיון. אם נתקעת, בקש hint אחד בלבד.

קצב: 3–4 תרגילים קלים ביום; 1–2 מתקדמים. בכל פתרון בדוק correctness, readability ו־runtime behavior.

רמה 1 — Compiler, Inference ו־Primitive Types

1. Compile ראשון

צור src/index.ts, הרץ עם tsx ובדוק עם tsc --noEmit. הסבר transpilation מול type checking.

2. Type Inference

הגדר string, number ו־boolean בלי annotations. נסה להציב טיפוס אחר והסבר מה TypeScript הסיק.

3. Annotation מיותר

קבל קוד שבו כל local variable annotated. הסר annotations שה־compiler מסיק בלי לאבד מידע.

4. Literal Widening

השווה let status = 'pending',‏ const status = 'pending' ו־annotation literal. בדוק את הטיפוס בכל מקרה.

5. any מול unknown

כתוב פונקציה שמקבלת ערך חיצוני פעם כ־any ופעם כ־unknown. הראה איזו גרסה מאפשרת bug ואיזו מחייבת בדיקה.

6. null ו־undefined

מודל user עם nickname חסר. כתוב פונקציה שמחזירה display name בלי non-null assertion.

7. void

כתוב logger שאינו מחזיר ערך. השווה פונקציה שמוצהרת void לפונקציה שמסיקה undefined.

8. never

כתוב פונקציה שתמיד זורקת ופונקציה עם infinite loop. בדוק מדוע הטיפוס הוא never ולא void.

9. Type Erasure

קמפל interface ו־type alias ל־JavaScript. זהה מה נעלם והסבר למה אי אפשר לבדוק interface עם instanceof.

10. Read the Error

צור שלוש שגיאות assignability שונות. לכל אחת כתוב: expected type, actual type והנתיב המדויק שבו הם מתנגשים.

שער 1

אתה מוכן להמשיך כשאתה יודע להסביר שה־compiler אינו runtime guard, ומעדיף inference כשאין צורך בחוזה מפורש.

רמה 2 — Arrays, Tuples ו־Object Modeling

11. Typed Arrays

כתוב פונקציה שמקבלת users ומחזירה active emails. אסור לשנות את המערך המקורי.

12. noUncheckedIndexedAccess

קרא index שאולי אינו קיים וטפל ב־undefined בלי !.

13. Readonly Array

שנה API כך שיקבל readonly Product[]. אתר mutation שה־compiler חוסם והחזר עותק חדש.

14. Tuple

מודל coordinate ו־HTTP result קצר כ־tuples. הוסף labels והסבר מתי object יהיה ברור יותר.

15. Object Type

הגדר Product עם id, name, price ו־active. כתוב formatter שלא תלוי בשדות מיותרים.

16. Optional Property

מודל address אופציונלי. הבדל בין property שלא קיימת לבין property מסוג string | undefined תחת exactOptionalPropertyTypes.

17. readonly Property

הגן על id ו־createdAt משינוי. בדוק מה readonly מונע בזמן compile ומה JavaScript עדיין יכול לעשות בזמן runtime.

18. Interface מול Type

מודל User בשתי הדרכים. הרחב interface ויצור union באמצעות type. כתוב מתי הבחירה באמת משנה.

19. Structural Typing

העבר object עם שדות נוספים לפונקציה שמבקשת shape קטן. אחר כך העבר object literal ישירות והסבר excess property checking.

20. Record בטוח

בנה lookup של products לפי id. טפל בכך שמפתח עשוי לא להימצא; אל תניח שכל string קיים.

רמה 3 — Functions ו־Contracts

21. Parameters ו־Return

כתוב calculateTotal עם input/output מפורשים בגבול module. הימנע annotation מיותר בתוך הגוף.

22. Optional מול Default

כתוב paginate עם page size ברירת מחדל. השווה parameter אופציונלי לפרמטר עם default.

23. Rest Parameters

כתוב sumPrices שמקבל מספר משתנה של prices ומונע string.

24. Function Type

הגדר predicate ו־mapper כ־type aliases והשתמש בהם ב־filter/map מותאמים.

25. Callback Contract

כתוב retry שמקבל operation. הגדר במפורש מספר attempts והתנהגות שגיאה בלי any.

26. Overloads

כתוב parseInput שמקבל string או Buffer ומחזיר תוצאה מתאימה. השווה overloads ל־union פשוט.

27. this Parameter

אתר callback שמאבד this. תקן עם arrow function או explicit this type והסבר runtime מול type system.

28. Higher-Order Function

כתוב withTiming ששומר על פרמטרים ו־return type של הפונקציה המקורית.

29. Dependency Contract

הגדר Clock עם method אחד והזרק fake clock לבדיקה. אל תעביר Date ישירות לכל הקוד.

30. API Surface

קבל פונקציה שמחזירה object פנימי גדול. עצב return type קטן ויציב שמסתיר implementation details.

רמה 4 — Unions, Literals ו־Narrowing

31. Union ראשון

פונקציה מקבלת string או number id. בצע narrowing בלי casting.

32. Literal Union

החלף status חופשי ב־'pending' | 'paid' | 'cancelled'. ודא שערך לא חוקי נחסם.

33. typeof Narrowing

עבד input שהוא string, number או undefined והחזר representation אחיד.

34. in Operator

הבחן בין EmailNotification ו־SmsNotification לפי property ייחודית.

35. instanceof

טפל ב־Date וב־Error class אמיתי. הסבר מדוע instanceof אינו עובד עם interface.

36. Custom Type Guard

כתוב isUser(value: unknown): value is User שבודק shape מינימלי בזמן runtime.

37. Assertion Function

כתוב assertion ל־environment variable חובה. לאחר הקריאה ה־compiler צריך לדעת שזה string.

38. Discriminated Union

מודל result כ־success/data או failure/error. כתוב consumer ללא optional fields.

39. Exhaustiveness

הוסף variant חדש ל־PaymentState. גרום ל־switch להיכשל compile עד שכל המצבים מטופלים באמצעות never.

40. State Machine

מודל transitions חוקיים של order. מנע shipped→pending כבר ב־API של הפונקציה ככל שניתן.

שער 2

אתה מוכן ל־generics כשאתה יודע למודל states ולצמצם unknown בלי assertions שמספרות ל־compiler סיפור לא מוכח.

רמה 5 — Generics

41. Identity Generic

כתוב identity ששומר את הטיפוס המדויק. השווה ל־unknown ול־any.

42. Generic Pair

כתוב Pair<K,V> והשתמש ב־string/number וב־id/User.

43. first

כתוב first ל־readonly array. ה־return type חייב להכיר אפשרות מערך ריק.

44. Constraint

כתוב getId שמקבל רק אובייקט עם id, בלי לאבד שדות נוספים.

45. keyof

כתוב getProperty שמחזיר את הטיפוס המדויק של property ולא union של כל values.

46. Generic Repository

הגדר Repository<T,Id> עם findById/save/delete. טפל ב־not found במפורש.

47. ApiResponse

מודל response generic עם metadata pagination. מנע מצב success ללא data.

48. Generic Defaults

בנה Event<Payload=undefined>. אירוע ללא payload לא יחייב argument; אירוע עם payload כן.

49. Preserve Signature

כתוב wrapper ל־logging ששומר parameter tuple, return type ו־async behavior.

50. Over-Generic Design

קבל service עם חמישה type parameters שאין ביניהם קשר. פשט אותו והסבר מתי generic מוסיף קשר ומתי רק מורכבות.

רמה 6 — Advanced Types

51. keyof ו־Indexed Access

הפק union של User keys וטיפוס הערך של User['email']. בנה selector בטוח.

52. typeof

הגדר config value עם as const והפק ממנו union של environments בלי לשכפל strings.

53. Partial

מודל update DTO עם Partial, ואז מנע עדכון id/createdAt באמצעות Omit.

54. Pick ו־Omit

צור PublicUser שלא חושף passwordHash. הסבר למה type בלבד לא מסיר property מ־object בזמן runtime.

55. Required ו־Readonly

הפוך draft config ל־validated config מלא ו־readonly אחרי validation.

56. Mapped Type

צור Errors<T> שממפה כל field ל־string[] אופציונלי.

57. Key Remapping

צור getter methods מטיפוס model באמצעות mapped type ו־template literal keys.

58. Conditional Type

כתוב UnwrapPromise<T>. בדוק Promise<User> מול User.

59. infer

הפק element type ממערך ו־return type מפונקציה באמצעות infer, ואז השווה ל־utility types מובנים.

60. Distributive Conditional

בדוק conditional על union והראה כיצד לעטוף ב־tuple כדי למנוע distribution כשזה נדרש.

61. Template Literal Type

הגדר event names כמו user.created מתוך entity/action unions.

62. Branded Types

צור UserId ו־OrderId שלא ניתנים להחלפה בטעות, עם constructors שעוברים runtime validation.

63. satisfies

הגדר route map שבודק התאמה לחוזה אך שומר literal inference. השווה annotation ול־as assertion.

64. as const

צור permission list immutable והפק ממנו Permission union. הסבר shallow readonly.

65. Type Challenge מעשי

מודל typed event bus שבו event name קובע במדויק את payload של publish ושל subscribe.

רמה 7 — Classes, Modules ו־Architecture

66. Class Contract

כתוב Money class שמגן על amount/currency. מנע חיבור מטבעות שונים בזמן runtime.

67. Access Modifiers

השווה private של TypeScript ל־#private של JavaScript ובדוק output runtime.

68. Implements

ממש EmailSender ו־FakeEmailSender תחת interface קטן.

69. Abstract Class

בנה base Job עם template method. השווה composition והחלט איזו גישה מתאימה.

70. Parameter Properties

כתוב service עם constructor injection וקצר אותו באמצעות parameter properties בלי לפגוע בקריאות.

71. Module Boundaries

פצל domain, application ו־infrastructure. מנע מה־domain לייבא database adapter.

72. import type

המר imports שמשמשים רק כטיפוסים ל־import type ובדוק JavaScript output.

73. ESM מול CommonJS

הקם project קטן ב־Node ESM. הסבר package type, module/moduleResolution ו־file extensions.

74. Circular Dependency

צור מעגל imports, צפה בהתנהגות ופרק אותו באמצעות dependency inversion או shared contract.

75. Decorator Boundary

כתוב method decorator לימודי ל־timing. הסבר מה decorator עושה בזמן runtime ומה metadata אינו מספק לבד.

רמה 8 — Async, Errors ו־Runtime Boundaries

76. Promise Return

כתוב async function עם return type מפורש. צור שגיאה של Promise<Promise<T>> רעיונית והסבר flattening.

77. Promise.all

טען user ו־orders במקביל ושמור tuple inference. הסבר fail-fast.

78. Promise.allSettled

עבד כמה providers כאשר failure אחד לא צריך לבטל הכול. Narrow לפי status.

79. unknown ב־catch

טפל ב־Error, string וערך לא צפוי בלי assertion עיוור.

80. Result Type

החלף exception צפויה ב־Result discriminated union. קבע אילו failures עדיין צריכים throw.

81. fetch אינו Type-Safe

קבל JSON מ־fetch כ־unknown, אמת אותו ורק אז החזר User. אסור as User.

82. Runtime Schema

התקן Zod או כתוב validator קטן. הפק/התאם static type ובדוק payload שגוי.

83. Environment Variables

בנה loadConfig שמאמת PORT, DATABASE_URL ו־NODE_ENV פעם אחת ומחזיר config typed מלא.

84. AbortSignal

כתוב client async שמקבל AbortSignal. הבדל cancellation בזמן runtime מה־Promise type.

85. Async Iterator

בנה async generator שמחזיר records בעמודים. עצור נכון ודאג לשחרור resource.

רמה 9 — TypeScript ב־Backend אמיתי

86. Request Boundary

קבל body כ־unknown, validate, map ל־command ורק אז קרא service. הפרד DTO מ־domain model.

87. Response DTO

מפה User entity ל־PublicUserDTO והוכח ש־passwordHash לא נמצא ב־object runtime.

88. Typed Route Params

אמת id מה־URL והמר ל־branded id. אל תסתפק ב־annotation על string.

89. Repository Boundary

הגדר interface ב־application layer ומימוש memory + PostgreSQL skeleton. טפל ב־not found ובכשל DB בנפרד.

90. Domain Errors

צור union של validation/conflict/not-found ו־exhaustive mapper ל־HTTP statuses.

91. Authentication Context

מודל unauthenticated מול authenticated request בלי property אופציונלית שנגישה בכל מקום.

92. Authorization

בנה can(user, action, resource) עם literal unions. זכור שהחלטת הרשאה חייבת לרוץ runtime.

93. Event Contracts

הגדר order events עם version ו־payload. ודא consumer מטפל בגרסה לא מוכרת.

94. ORM Generated Types

קבל entity generated עם relations אופציונליות. אל תניח relation loaded; עצב projection/query return type ברור.

95. External Provider Adapter

עטוף SDK שהטיפוסים שלו רחבים. validate response, map errors וחשוף interface יציב לאפליקציה.

רמה 10 — Tooling, Testing ו־Production

96. Strict tsconfig

הפעל flags אחד־אחד בפרויקט קטן. לכל שגיאה סווג bug אמיתי, assumption חסר או typing לא מדויק.

97. Type Tests

כתוב assertions מסוג @ts-expect-error למקרים שחייבים להיכשל. ודא שהבדיקה נכשלת אם האיסור נעלם.

98. Runtime Tests

בדוק validator עם valid/invalid/boundary payloads. הסבר למה compile success אינו מחליף test.

99. Unsafe Code Audit

חפש any, assertions, non-null, ts-ignore ו־unchecked JSON. לכל שימוש: הוכחה, validation או redesign.

100. Refactoring Capstone

קח module JavaScript קיים והעבר ל־strict TypeScript בשלבים. אל תשנה behavior; הוסף characterization tests לפני refactor.

שער סיום

אתה מוכן לעבוד עם TypeScript ב־Backend כשאתה יודע למודל states, לאמת גבולות runtime, לקרוא שגיאות compiler ולהסביר היכן type safety נגמרת.

8 מעבדות מסכמות

מעבדה 1 — Strict Migration

העבר utility library קטנה מ־JavaScript ל־strict TypeScript בלי any. תוצר: tsconfig, tests ודוח assumptions שהתגלו.

מעבדה 2 — Domain Modeling

מודל order lifecycle עם discriminated unions, branded IDs, Money ו־exhaustive transitions. תוצר: domain module שאינו תלוי ב־HTTP או DB.

מעבדה 3 — Typed Event Bus

בנה publish/subscribe שבו event name קובע payload, כולל unsubscribe ו־async handlers. תוצר: implementation, type tests ו־runtime tests.

מעבדה 4 — API Boundary

בנה endpoint ליצירת user: unknown input, runtime schema, DTO mapping, service result ו־safe response. תוצר: tests ל־invalid payload ולדליפת secret.

מעבדה 5 — External API Client

בנה client עם timeout, AbortSignal, retries מוגבלים, validation ו־typed errors. תוצר: fake transport ובדיקות failure modes.

מעבדה 6 — Repository Architecture

בנה service עם Repository interface, memory adapter ו־PostgreSQL adapter skeleton. תוצר: אותו contract test לשני adapters.

מעבדה 7 — Background Job System

מודל job states ו־payload map לכמה job types. טפל ב־retry/dead-letter ובאירוע לא מוכר. תוצר: worker typed עם tests.

מעבדה 8 — Backend Capstone

בנה API קטן ב־Node/NestJS: auth context, validation, domain errors, repository, logging ו־tests. תוצר: strict build ללא any/ts-ignore והסבר היכן מתבצעת כל בדיקת runtime.
